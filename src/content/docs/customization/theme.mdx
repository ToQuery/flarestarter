明暗主题切换与配色。全站（营销页、App、文档）共用一套 [next-themes](https://github.com/pacocoursey/next-themes)
状态：**显式选择 > 系统偏好 > 深色**，切换只改 `<html>` class 和 `localStorage`，不产生服务端请求。

> **fork 后你要改哪:** 换配色改 `src/styles/app.css` 的 CSS 变量；改默认主题改
> `src/features/theme/provider.tsx` 的 `defaultTheme`。

## 工作原理

- **Provider**：`src/features/theme/provider.tsx` 封装 `next-themes`，配置
  `attribute="class"`、`defaultTheme="system"`、`storageKey="theme"`。
- **首绘**：next-themes 在 `<body>` 顶部注入一段内联脚本，在内容绘制前读取
  `localStorage` / 系统偏好并给 `<html>` 加上 `light` 或 `dark`，所以没有闪烁。
- **切换**：`ThemeToggle`（`src/features/theme/theme-toggle.tsx`）只调
  `setTheme(resolvedTheme === 'dark' ? 'light' : 'dark')`；不写 cookie，也不调
  `router.invalidate()`。
- **docs 同步**：文档页的 `RootProvider` 设了 `theme={{ enabled: false }}`，复用根节点的
  next-themes context；文档站右上角的主题按钮和主站是同一个 store。
- **Toaster**：`ThemedToaster` 用 `useTheme().resolvedTheme` 跟随当前主题。

## 改配色

配色集中在 `src/styles/app.css` 的 CSS 变量：

- `:root` 定义浅色令牌（`--bg`、`--fg`、`--accent` 等）；
- `:root.dark, .dark` 覆盖为深色值；
- `@theme inline` 把这些变量映射成 Tailwind v4 的 `--color-*`，组件里就能用
  `bg-background`、`text-fg-2` 这类类名。

改品牌色只需动这几处变量，明暗两套各改一遍即可。

<Callout type="info">
想默认浅色？把 `provider.tsx` 里的 `defaultTheme` 改成 `"light"`。用户一旦点过切换，
`localStorage` 里的显式选择仍然优先。
</Callout>
